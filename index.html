Categories
Tattalin Arziki (final sign)

These 3 texts are shown based on the goodness of the final composed sign only — write one set of answers per outcome.

Zargi (final sign)

Shown only when the ZARGI category is active. Resulting sign = Tauraron gidan shidan dali'i (house 6) + Tauraron gidan takwas din dali'i (house 8). Write one set of answers per goodness outcome.

Zuba Kudi a Kasuwanci/Wata Harka (Tafiya final sign)

Shown only when the ZUBA KUDI A KASUWANCI/WATA HARKA category is active, based on the goodness of the Tafiya final composed sign — write one set of answers per outcome.

Sayan Fili/Gida (Mumajaza final sign)

Shown only when the SAYEN FILI/GIDA category is active. Resulting sign = Tauraron gidan hudun dali'i + Tauraron gidan takwas din dali'i. Write one set of answers per outcome, based on which of the two the result has Mumajaza with.

Samun Alheri A Wata Harka (Mumajaza final sign)

Shown only when the SAMUN ALHERI A WATA HARKA category is active. Resulting sign = Tauraron gidan biyun dali'i + Tauraron gidan takwas din dali'i. Write one set of answers per outcome, based on which of the two the result has Mumajaza with (or neither).

Komen Aure \u2014 Interpretation 1

Shown only when the KOMEN AURE category is active and at least one of the 4 trigger conditions holds. Single shared text.

Komen Aure \u2014 Interpretation 2

Shown only when the KOMEN AURE category is active. Resulting sign = Tauraron gidan shidan dali'i (house 6) + Tauraron gidan bakwai din dali'i (house 7). Write per outcome: which source it matches, or which nature (if it matches both).

Komen Aure \u2014 Interpretation 3

Shown only when the KOMEN AURE category is active and Madlubin dali'i lands on the house where its own Infisali is hidden, on Gidan sha hudun dali'i (14), Gidan takwas din dali'i (8), or Gidan sha biyun dali'i (12). Same shared base text for all triggers.

Komen Aure \u2014 Interpretation 3 extra texts

Appended alongside the Interpretation 3 base text: "death" when Madlubin dali'i lands on Gidan takwas din dali'i (8); "enemies" when it lands on Gidan sha biyun dali'i (12).

Inda Abin Nema Yake (direction)

Shown only when the INDA ABIN NEMA YAKE category is active. Sign = Madlubin dali'i's occupied physical house (first/lowest if more than one), or the Gidan bakwai din dali'i house as fallback if not found. Write one set of answers per nature outcome (Fire=gabas, Air=yamma, Water=kudu, Earth=arewa).

Inda Zakaje Neman Arziki (direction to seek wealth)

Shown only when the INDA ZAKAJE NEMAN ARZIKI category is active. Sign = "tauraron 2 na dali'i" (asalin sa) \u2014 the sign identity whose Tauraron offset-2 relationship to Dali'i applies, NOT the occupant of the Dali'i-offset-2 house. Search all 16 physical houses for that identity; if found (possibly repeated \u2014 use LAST occurrence), direction depends on which quadrant (1-4/5-8/9-12/13-16) it falls in; if not found anywhere in the cast, show the "stay where you are" fallback.

Me Zan Karanta? (what to study)

Shown only when the ME ZAN KARANTA? category is active. Resulting sign = Dali'i (house1) + Tauraron gidan 9 na dali'i + Tauraron gidan 7 din dali'i, figure-added together (chained). Keyed by resulting sign's nature (Fire/Air/Water/Earth). Write both secular and religious field suggestions per outcome.

Noma/Kiwo (farming/herding)

Shown only when the NOMA/KIWO category is active. Resulting sign = Dali'i (house1) + Tauraron gidan 4 na dali'i + Tauraron gidan 2 na dali'i, figure-added together (chained). Keyed by resulting sign's nature (Fire/Air/Water/Earth). Write both a farming (noma) text and a herding (kiwo) text per outcome.

Tafiya \u2014 Inda Zaije (Destination)

Shown only when the TAFIYA category is active. Sign = Tauraron gidan bakwai din dali'i (house 7), keyed by its OWN goodness (no addition with another sign).

Tafiya \u2014 Hanyar Tafiya (Outward Road)

Shown only when the TAFIYA category is active. Sign = Tauraron gidan taran dali'i (house 9), keyed by its OWN goodness.

Tafiya \u2014 Hanyar Dawowa (Return Road)

Shown only when the TAFIYA category is active. Sign = Tauraron gidan sha biyar din dali'i (house 15), keyed by its OWN goodness. Same ruling as the outward road, own wording ("hanyar dawowar").

Tafiya \u2014 Masaukin Sa (Lodging)

Shown only when the TAFIYA category is active. Sign = Tauraron gidan hudun dali'i (house 4), keyed by its OWN goodness.

Tafiya \u2014 Bukatar (fulfillment of the trip's purpose)

Shown only when the TAFIYA category is active. Keyed by the Tafiya offset of the Madlubin Dali'i identity, searched against the real 16 cast occupants (falls back through Madlubi-of-Madlubi, then a third level, before using the fallback text).

Karfin Jalabi (open-dot count)

Shown only when the KARFIN JALABI DA DAFA'I category is active. Sign = Tauraron gidan biyar din dali'i. Write one set of answers per open-dot-count outcome (1/2/3 dots, or Dariki's special 4-dot case).

Karfin Dafa'i (closed-dot count)

Shown only when the KARFIN JALABI DA DAFA'I category is active. Sign = Tauraron gidan takwas din dali'i. Write one set of answers per closed-dot-count outcome (bias runs opposite to Karfin Jalabi).

Son Namiji (Male Love)

Shown only when SOYAYYA is active. Sign = physical house 1 + physical house 5. Write one set of answers per goodness outcome.

Son Mace (Female Love)

Shown only when SOYAYYA is active. Sign = physical house 3 + physical house 11. Write one set of answers per goodness outcome.

Sonka \u2014 Nature Result (Air-merge)

Shown only when SOYAYYA is active, and only if an air-nature sign appears in the chart. Merged air signs + Tauraron gidan ukun dali'i. Write one set of answers per nature outcome (Fire/Air/Water/Earth).
